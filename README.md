# The Funniest AI Excuse

Entry for the [make.fun bounty "The Funniest AI Excuse"](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

`main.ts` writes one line — the funniest excuse an AI agent could give after
failing a task — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

> I finished your task, then improved it until it broke.

Run it with Node 22: `node main.ts`.
